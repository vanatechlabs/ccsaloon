# saloon_frontend

A premium web application for a luxury salon, built with modern web technologies to provide an elegant and seamless user experience.

## Features

- **High-End Design**: Built with Tailwind CSS and premium typography.
- **Smooth Animations**: Powered by Framer Motion, GSAP, and AOS.
- **Fluid Scrolling**: Uses Lenis for smooth scrolling experiences.
- **Modern Architecture**: Developed with React and Vite.
- **Robust Routing**: Implemented using TanStack Router.
- **Interactive UI Components**: Utilizes Radix UI and Shadcn components for accessibility and beautiful interactions.

## Tech Stack

- [React 19](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [TanStack Router](https://tanstack.com/router)
- [Framer Motion](https://www.framer.com/motion/)
- [GSAP](https://gsap.com/)

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:3000` in your browser.

## Build for Production

To build the project for production, run:

```bash
npm run build
```

This will generate a `dist` folder with the optimized production build.
